# Web 管理交互、服务发现与 Keepalived/VIP

本轮入口为数据源、集群、站点、配置、证书、日志六项。Web 终端菜单、票据和连接路由退役；既有连接审计、数据表及历史角色关联保留。

## 页面交互

- 列表仍使用“详情、编辑、更多”，复用资产表格留白和居中分页；数据源和集群显示本地 Nginx SVG 图标，DNS 账户按服务商显示图标。
- 证书及其他弹窗挂载在 body，限定视口高度，正文独立滚动，确认按钮保持可见。Web 弹窗不修改 body 宽度锁，避免快速开关时旧清理任务影响新弹窗；标签切换重新建立相应表格列。
- 配置文件左栏提供滚动列表、搜索和 10/20/50/100 分页。Tab/Shift+Tab 缩进，Ctrl/Cmd+S 校验保存，Esc 后按 Tab 离开编辑器。新增或既有文件删除均需确认；确认只改变草稿，实际删除仍经过完整 Nginx 校验及发布。
- 站点表单分开原文与结构化模式，提供代理、静态、重定向规则和日志/健康检查设置；证书按当前集群部署绑定选择。建议配置路径来自实际实例目录，人工路径不会被自动覆盖。保存站点、生成草稿和发布为不同步骤。
- 日志按实例和登记日志标识查询，支持高级过滤、实时追踪/暂停、换行、复制、下载和前后扫描窗口。站点入口只匹配已登记访问/错误日志路径；多个站点共用文件时明确提示，不能把共享文件声称为独立站点日志。

## 简化数据源接入

选择 CMDB 主机和已有 SSH 档案后，点击“自动识别 Nginx”。`POST /api/v1/web/source-discovery` 只读检查运行中的主机进程或 Docker 容器，返回多个候选；每个候选分别包含真实二进制、配置入口、前缀、服务/容器身份和版本。

选择候选后填充高级参数；未发现服务时可以检查连接或手动补充高级设置。识别本身不会登记或接管实例。保存后可选择发现实例，默认为观察模式。已登记实例的数据源禁止改变定位，避免将历史操作指向另一进程。

## 集群拓扑与高可用

集群详情通过 `GET /api/v1/web/clusters/:id/topology` 展示业务入口、Nginx 成员、配置摘要和 VIP 真实观测；未配置 VIP 时不绘制虚构主备关系。

高可用标签填写用户已预留的 VIP/CIDR、网卡、VRID、2–10 个成员和首选节点。只支持不同 Linux 主机上的已接管 Nginx。各成员使用具体实例的健康地址，并验证监听端口确由该 Nginx master 提供。

操作沿用 `operation-plans` → `operations` → 任务核验：

| 动作 | 行为 |
| --- | --- |
| `configure-vip` | 校验 IP/VRID 冲突、网卡、ARP、权限、身份、健康和包版本，部署独立服务并验证唯一持有者及业务访问 |
| `verify-vip` | 重新核验成员服务、唯一绑定和通过 VIP 的 HTTP 访问 |
| `switch-vip` | 先确认其他成员健康，为原持有者设置独立救援定时器，停止该集群的 VIP 单元，核验新持有者后恢复原单元为备用 |
| `reconcile` | 检查原任务 journal、文件 manifest、源 revision、Nginx 身份和基线；不盲目重放未确定的部署或切换 |

参数示例（地址必须由管理员预留，不可照抄到其他环境）：

```json
{
  "targetType": "clusters",
  "targetId": 1,
  "action": "configure-vip",
  "parameters": {
    "vip": {
      "cidr": "192.168.80.110/24",
      "interface": "ens33",
      "routerId": 151,
      "instanceIds": [1, 2, 3],
      "preferredInstanceId": 1
    }
  }
}
```

每个集群使用 `/etc/autoops-web-vip/<clusterId>/` 和 `autoops-web-vip-<clusterId>.service`，配置、健康脚本、PID 与现有数据库 VIP 隔离。缺少 Keepalived 时使用预检冻结的软件包版本；安装期间抑制系统默认服务自动启动。现有系统或数据库 Keepalived 不会被统一重启。

配置采用单播 peers、不同优先级和 `nopreempt`，恢复后的原节点保持备用，避免反复抢占。VRRP 检测和地址切换需要时间，不能承诺连接零中断。参数依据 [Keepalived 配置文档](https://www.keepalived.org/documentation/keepalived-conf/)；程序选项见 [Keepalived 命令说明](https://www.keepalived.org/documentation/user-guide/programs-synopsis/)。
