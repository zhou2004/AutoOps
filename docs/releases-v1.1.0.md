# AutoOps v1.1.0 · Connected Operations

本次版本统一品牌与账号入口，并汇总资产、数据库、Web 管理和自动化模块的最新改进。

## 品牌与账号

- 新增 AutoOps 明暗双主题 SVG 图标，应用于导航、登录页与浏览器标签。
- 重做响应式动态登录页，提供中英文、低动态效果模式与清晰的键盘焦点。
- 修复验证码裁切与重复使用，移除预填管理员账号密码。
- 新增邮箱验证注册、管理员审批及邮件找回密码；验证码有有效期、发送限流与尝试次数限制。
- 新密码采用 bcrypt，兼容已有账号；邮件重置密码会使原有浏览器会话失效。

## 统一运维

- 机房管理整合世界地图、机柜与 U 位三维下钻，支持真实资产关联、主题与窗口自适应。
- 域名证书增加后台自动巡检，修复不足一天的证书过期判断。
- 完善数据库日志工作台、Web/Nginx/站点与证书管理、流量和防护、任务编辑与执行日志。
- 补全资产图标、细粒度授权和机房国际化。

## 安装与维护

- README 重构为产品概览、效果图、安装入口与分类文档。
- 提供源码、Docker Compose、Kubernetes 三种独立安装教程及初始化脚本。
- 提供干净的初始化 SQL，默认不导入示例业务数据；安装脚本为每次部署生成随机凭据。
- 配置模板与本地凭据分离，清理日志和 Windows 下载元数据；文档效果图统一迁入 assets/screenshots。
- GitHub Actions 发布 API/Web 镜像到 GitHub Packages（GHCR）及 Docker Hub，并生成版本 Release。

## 升级说明

1. 备份数据库、上传文件及 Web/AI 加密密钥，再更新前后端镜像到同一版本。
2. 原配置仍可使用；本地 `api/config.yaml`、`docker/.env` 不再由 Git 跟踪，示例配置使用 `.example` 后缀。
3. 已有 Docker 部署继续使用原卷与密码。新的 Compose 是全新安装模板，不要将其默认命名卷直接替换到旧部署；按安装文档中的升级说明映射原数据目录。
4. 后端启动会新增账号验证相关表。SMTP 可使用本机 `accountSMTP` 配置或 `AUTOOPS_SMTP_*` 环境变量，也可复用现有告警邮件配置。
5. 自助注册的用户默认禁用且不绑定角色，需管理员在用户管理中启用并分配权限。找回密码要求邮箱唯一对应一个现有账号。
