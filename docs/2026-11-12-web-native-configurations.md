# Web 原生配置与证书导入导出

本次范围为三台已接入的 Nginx 实例的原生配置管理、配置分组及证书导入导出。按本次需求调整，自动续期暂缓，不新建或修改续期策略。

## 原生配置

进入 **Web 管理 → 配置管理 → 实例配置**，选择实例后从远端读取主配置、include 依赖及受管目录内的 `conf.d` 文件。文件保留原文，包含注释和 Nginx 原生指令；不经过站点表单转换。未被入口引用的文件会单独标记，受管范围之外的依赖只能查看。

1. 在文件树选中文件编辑，或添加绝对路径的配置文件。已有文件删除后先显示“待删除”，可以撤销。
2. 可先点击“校验语法”。保存和发布仍会在服务端重新校验，无法通过直接调用保存接口绕过校验。
3. 默认只操作当前实例；选择“整个集群”才同步到其他成员。文件搜索或页面筛选不会缩小“整个集群”的目标。
4. “校验并保存草稿”只保存元数据。“校验并发布”保存通过校验的草稿并打开发布预检，确认后由 Worker 执行分批发布。
5. 任何目标节点的语法或引用检查失败，保存被拒绝，远端文件与服务保持原状。发布前还会重查身份、权限、文件基线；外部修改导致冲突时先重新读取并比较。

校验使用目标实例实际的 Nginx 二进制与候选文件树，包含新增、修改和删除后的结果。删除显式 include 所需文件会失败；通配 include 允许删除不再需要的独立片段。未引用的 `.conf` 片段也必须经过校验，不能用“不在入口中”绕过语法检查。复杂的非 HTTP 片段应在候选主配置中显式 include，以确定正确语法上下文。

“发布草稿”保留高级文件编辑、节点变量、版本与发布入口。直接修改平台生成的站点文件后，站点按原文维护，避免结构化表单覆盖人工修改。

## 配置分组

在 **配置分组** 标签新增分组，选择集群，填写每行一个的配置文件绝对路径。分组属于集群，同一文件不能重复属于多个分组。实例配置支持按分组、未分组、路径或内容、已修改状态筛选；发布草稿可按所属配置分组筛选。

保存草稿时选择分组，会把本次非删除文件加入该分组。分组只组织配置文件，不重命名文件，也不改变 Nginx include 和发布目标。

## 证书导入与导出

进入 **Web 管理 → 证书管理**，点击顶部“导入证书”，填写资产名、业务分组、环境，并选择或粘贴 PEM 证书链与私钥。域名、有效期、签发者、指纹由证书解析。检查失败不会创建空证书资产，检查成功后私钥加密保存。

已有资产行的“更多”菜单提供“导入证书”“证书版本”和导出操作；导入创建新版本，从版本记录可以导出指定历史版本。证书链与私钥分别下载，不会把私钥混入公开证书文件。私钥导出仅允许具有模块写权限和证书管理授权的管理员，并记录操作审计；审计失败时拒绝导出。导出响应禁止缓存。

导入成功表示证书版本已保存，不表示已替换线上证书。现有证书绑定和部署仍使用独立发布流程；本次操作不会自动启动续期或替换线上证书。

## 接口补充

| 接口 | 合约 |
| --- | --- |
| `GET /api/v1/web/instances/:id/config` | 实时读取文件，包含 `editable`、`included`、实例身份与基线摘要 |
| `POST /api/v1/web/clusters/:id/config/validate` | `{files, instanceIds?, baselines?, variables?}`；逐节点返回校验结果 |
| `POST/PUT /api/v1/web/configurations[/id]` | 保存前强制完整候选语法校验；`spec.instanceIds` 为空时沿用全群语义 |
| `/api/v1/web/config-groups` | `spec.paths` 为分组内文件路径；集群内唯一归属 |
| `POST /api/v1/web/certificates/import` | `{name, groupId, environment, certificate, privateKey}` → `{certificate, version}` |
| `POST /api/v1/web/certificates/:id/import` | 为已有资产导入新版本 |
| `GET /api/v1/web/certificates/:id/versions` | 版本元数据、当前版本及有效期 |
| `GET /api/v1/web/certificates/:id/versions/:versionId/export?key=false` | 导出证书链；`key=true` 受私钥管理权限限制；版本 `0` 表示当前版本 |

发布计划冻结目标、草稿修订号及内容摘要。计划执行后只有仍与冻结内容一致的草稿才标记为已发布；历史回滚和中断核验保持原发布目标，不扩展到后来加入的节点。

实测记录见 [Web 管理验收记录](web-management-validation.md)。
