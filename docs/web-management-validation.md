后端不接受任意日志路径，沿用已登记标识；连接开始/结束有审计。范围、文件或筛选变更中止旧流。实时缓冲限制 10000 行/2 MiB UTF-8，包含中文及 emoji 的边界测试。重连读取最新窗口，不宣称断线期间无损恢复。
