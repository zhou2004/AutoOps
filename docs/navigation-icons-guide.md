# 全站菜单图标与对齐

2026-11-04 更新。各模块导航统一使用本地图标，覆盖首页、AI 运维、资产管理、数据库管理、容器管理、任务中心、监控中心、配置中心、运维工具、服务管理及基础管理。

- 路由使用 `menuIcon(path)`，映射集中在 `web/src/utils/menuIcons.ts`。图标从本地 `@element-plus/icons-vue` 取得，不依赖外网请求；保留已有 SVG 和自定义 Iconfont 的渲染能力。
- 图标列固定 18px，图标与文字间距 10px；侧栏与弹出菜单行高固定 44px。同一级文字起点一致，折叠时图标居中。长标题使用原有省略与提示，层级缩进沿用 Element Plus。
- 混合、横向和折叠菜单使用同一套图标解析与占位；横向模式沿用原顶栏高度。新动态菜单未配置图标时显示默认 Menu 图标。
- API 菜单元数据迁移补齐空图标、规范旧的 ep/ri 格式默认图标名称；保留自选图标、菜单路径、排序、启停状态、权限与角色关联。默认映射与前端通过对照测试校验。

维护入口：

| 范围 | 文件 |
| --- | --- |
| 图标映射 | `web/src/utils/menuIcons.ts` |
| 可见菜单 | `web/src/router/modules/` |
| 侧栏及弹出菜单 | `web/src/layout/components/lay-sidebar/components/SidebarItem.vue` |
| 混合顶部导航 | `web/src/layout/components/lay-sidebar/NavMix.vue` |
| 公共尺寸样式 | `web/src/style/design-system.css` |
| 菜单图标默认值 | `api/pkg/db/menu_icons.go` |

新增菜单时为新路径选择恰当的本地图标，同时更新前后端映射。不要使用未注册的 `ep/xxx` 字符串直接渲染图标。图标只是视觉呈现，不改变该菜单的访问权限。

## 验证结果

- 前端构建与菜单元数据迁移测试通过。
- 浏览器逐项核验 11 个主入口（含仪表盘）、52 个子菜单；10 个可展开模块的同级文字起点一致，图标为 18px，侧栏行高为 44px。
- 折叠居中、弹出菜单、横向导航、混合导航、深浅主题和 800px 窄屏通过；无页面异常或外部图标请求。
- 已执行仅更新图标字段的元数据补齐函数，保留菜单授权、排序、路径和启停状态。
