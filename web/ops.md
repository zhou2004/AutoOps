## 设计风格

企业级运维管理平台 UI 风格方案（多主题+极简风）
 
整体定位：企业专业风、轻量化极简、高兼容性、支持海量自定义主题，默认搭载「经典白」「深邃黑」两套标配主题，兼顾运维人员长时间办公的视觉舒适、操作高效、数据清晰三大核心诉求。
 
一、整体设计核心原则
 
1. 极简优先：弱化冗余装饰，功能分区明确，减少视觉干扰，适配运维高频操作、大屏监控、多窗口并行场景。
2. 高对比度：文字/数据/状态色区分清晰，强光工位、暗光机房均可正常查看。
3. 主题解耦：色彩、圆角、阴影、间距、图标全部抽离为主题变量，支持可视化自定义配色、样式参数，一键切换/保存主题。
4. 响应式布局：适配桌面大屏、普通显示器、窄屏工作站，布局不错乱。
5. 运维场景适配：突出数据面板、告警状态、服务状态、日志列表、拓扑图等核心模块。
 
 
 
二、全局基础规范（全主题通用框架）
 
1. 布局结构（固定骨架，主题仅改色）
 
采用经典三段式运维布局，全主题统一结构，降低切换学习成本：
 
- 顶部导航栏(支持缩放)
- 左侧侧边栏(支持缩放)
- 主内容区
 
2. 通用组件规则（全主题统一样式逻辑）
 
- 圆角：统一小圆角  4px （偏严谨企业风，不使用大圆角/圆润萌系风格）
- 边框：细线条  1px  分割，无粗边框
- 阴影：浅投影，仅用于悬浮、弹窗、卡片层级区分，避免厚重阴影
- 间距：统一栅格间距，模块留白适中，紧凑不拥挤
- 图标：线性简约图标（线框为主，少量填充状态图标），图标尺寸统一，风格统一（运维工具风，不使用卡通图标）
- 字体：
中文：微软雅黑 / 思源黑体（办公通用、清晰易读）
英文/数字：Inter（数据、IP、日志、代码展示最优）
字号层级：标题 > 正文 > 辅助文字，层级差固定
 
3. 状态色（全主题语义统一，颜色随主题明暗微调）
 
运维标准状态色（语义不变，亮度/饱和度适配黑白主题）：
 
- 正常/在线：绿色
- 告警/异常：红色
- 警告/待处理：橙色
- 离线/禁用：灰色
- 运行中/加载：蓝色
- 次要提示：浅灰
 
 
 
三、默认两套标准主题（黑白标配）
 
主题一：经典白主题（默认浅色模式，办公主流）
 
1. 主色调
 
- 背景色：页面底色  #FFFFFF ，卡片底色  #F8F9FA （浅灰白，护眼不刺眼）
- 主品牌色：企业中性蓝  #1677FF （按钮、选中菜单、高亮数据、操作入口）
- 分割线/边框： #E5E6EB  浅灰细线条
 
2. 文字层级
 
- 一级标题/重要数据： #1D2129 （深黑）
- 正文常规文字： #4E5969 （深灰）
- 辅助文字/备注/时间： #86909C （浅灰）
 
3. 模块视觉细节
 
- 侧边栏：白底+蓝色选中态，hover 浅灰底色
- 数据卡片：白底微阴影，hover 轻微上浮
- 数据表格：斑马纹浅灰行，选中行蓝色高亮
- 告警标签：白底+彩色文字/小边框
- 按钮：主按钮蓝色填充，次按钮白底灰边框，文字按钮无背景
 
4. 适用场景
 
日常办公、强光环境、长时间浏览报表/日志。
 
 
 
主题二：深邃黑主题（深色模式，机房/夜间值守首选）
 
1. 主色调
 
- 页面底色： #0F1419 （深炭黑，非纯黑，减少视觉疲劳）
- 卡片/面板底色： #1E2937 （深灰蓝，分层区分层级）
- 主品牌色：亮蓝  #36A3FF （提亮，保证深色下辨识度）
- 分割线/边框： #333F4E （暗灰线条，不突兀）
 
2. 文字层级
 
- 一级标题/重要数据： #F5F7FA （纯白）
- 正文常规文字： #C9CDD4 （浅灰白）
- 辅助文字/备注/时间： #86909C （中性灰）
 
3. 模块视觉细节
 
- 侧边栏：深色底+亮蓝选中态，hover 加深底色
- 数据卡片：深色底弱阴影，整体静谧
- 数据表格：深色斑马纹，选中行亮蓝高亮
- 告警标签：深色底+高饱和状态色，醒目不刺眼
- 按钮：主按钮亮蓝填充，次按钮深色灰边框
 
4. 适用场景
 
机房值守、夜间运维、多屏监控大屏、长时间盯屏。
 
 
 
四、自定义主题系统（核心能力：海量主题自由配置）
 
平台内置可视化主题编辑器，支持全维度自定义，所有样式均为可配置变量，无需改代码。
 
1. 可自定义维度（全覆盖）
 
1. 色彩体系（核心）
- 页面背景、卡片背景、侧边栏背景
- 主品牌色、辅助色、高亮色
- 文字三色（标题/正文/辅助）
- 边框、分割线、hover 底色
- 状态色（正常/告警/警告/离线 可单独改色）
2. 样式形态
- 圆角大小（0px~12px 自由调节：直角/小圆角/大圆角）
- 阴影强度（无阴影/弱阴影/强阴影）
- 线条粗细（边框、分割线）
- 图标样式（纯线框/线框+填充）
3. 布局风格
- 侧边栏配色模式（同页面/独立配色）
- 卡片样式（简约无边框/有线边框）
- 表格样式（斑马纹开启/关闭）
 
2. 主题管理功能
 
- 主题新建、编辑、删除、重命名
- 主题导出/导入（团队共享主题包）
- 设为默认主题、一键切换（顶部下拉菜单，1秒切换）
- 主题分组（浅色组、深色组、企业定制组）
- 预设模板库：内置商务蓝、极简灰、科技青、暗夜紫、工业橙等数十套成品模板，一键套用再微调
 
3. 权限控制（企业级需求）
 
- 管理员：可编辑全局公共主题、新增平台默认模板
- 普通用户：可个人自定义私人主题，仅本人可见
 
 
 
五、核心页面视觉效果参考（极简运维风）
 
1. 首页运维大盘
 
- 布局：多卡片网格化布局（主机状态、服务拓扑、告警统计、资源使用率、待办工单）
- 风格：无多余装饰，数据优先，图表使用简约折线/柱状/环形图，配色跟随当前主题
- 交互：卡片点击下钻详情，数字实时跳动
 
2. 主机/服务器管理页
 
- 主体：大数据表格（IP、名称、状态、系统、负载、运行时长）
- 操作列：图标按钮（详情、远程、重启、停机），紧凑排列
- 筛选区：顶部简约搜索+下拉筛选，无复杂表单
 
3. 告警中心
 
- 标签化区分告警等级，状态色醒目
- 列表简洁，优先展示告警对象、级别、时间、内容
- 已处理/未处理分组清晰
 
4. 系统设置-主题配置页
 
- 左侧预览区（实时预览主题效果）
- 右侧参数配置面板（取色器、滑块、开关）
- 操作按钮：保存、重置、应用、设为默认
 
 
 
六、交互体验规范（全主题统一，保证好用）
 
1. 轻量化交互：所有弹窗、下拉、菜单弹出动画极淡，不花哨，保证操作效率
2. 焦点提示：选中、hover、点击状态反馈明确，盲人/弱视觉也可识别
3. 深色模式自适应：支持跟随系统明暗模式自动切换黑白主题
4. 快捷键兼容：运维常用快捷键不受主题影响
5. 无视觉抖动：主题切换瞬间完成，布局、组件位置完全不变
